# PyTorch: аппроксимация функции двух переменных

Практика по PyTorch: обучение нейросети, которая по паре чисел (x, y) предсказывает значение функции

```
f(x, y) = sin(x + 2y) * exp(-(2x + y)^2),   x, y из [-10; 10]
```

## Задание

1. Создать и обучить регрессионную модель, которая аппроксимирует функцию на диапазоне [-10; 10] по x и y.
2. Сгенерировать обучающую выборку из 20 000 случайных точек.
3. Разделить данные на train / val / test в отношении 70% / 15% / 15%.

Результаты:
- a) MSE на test;
- b) график сравнения истинной функции и её аппроксимации.

## Особенность функции

Функция заметно отлична от нуля только в узкой полосе вдоль прямой y = -2x (~10% точек), внутри которой знак чередуется с периодом ~2.1. На остальной площади она почти равна нулю.

Качество моделей сравнивается с baseline. Модель, которая всегда предсказывает 0, получает MSE ~ 0.016.

## Решение

### Модель 1: MLP
- архитектура 2 -> 128 -> 128 -> 128 -> 1, активация Tanh;
- нормализация входов по train;
- Adam (lr = 1e-3), ReduceLROnPlateau, 300 эпох, батч 256;
- выбор лучших весов по val.

Результат: модель почти не отличается от baseline. Обычный MLP плохо выучивает мелкие быстро меняющиеся детали (spectral bias), а 90% точек с нулевым значением тянут предсказание к нулю.

### Модель 2: Fourier features + MLP
- входы (x, y) преобразуются в 256 признаков;
- дальше тот же MLP;
- Adam (lr = 1e-3), CosineAnnealingLR, 300 эпох.

Готовые синусоидальные признаки позволяют сети собирать высокочастотные детали из комбинации волн.

## Результаты

Модель - MSE на test 

Константа 0 (baseline) - 1.55e-2
Модель 1: MLP + Tanh - 1.42e-2 
Модель 2: Fourier features + MLP - 8.66e-7

- RMSE на test ~ 9.3e-4 (~0.1% от амплитуды функции);
- R^2 ~ 0.9999;
- модель 2 лучше baseline примерно в 18 000 раз;
- MSE на test того же порядка, что на val;
- предсказание визуально совпадает с истинной функцией.

## Вывод

Архитектура модели должна соответствовать структуре данных. Обычному MLP не помогло бы ни увеличение числа эпох, ни подбор learning rate, а преобразование входов (Fourier features) решило задачу.
