# Предсказание популярности статей Хабра по тексту

Учебный проект: парсинг данных с сайта и построение NLP-модели.

## Задача

Собрать датасет с помощью парсинга веб-страниц и построить модель, которая по тексту статьи предсказывает её популярность.

- **Сайт:** [Хабр](https://habr.com), хаб "Машинное обучение"
- **Текст:** полный текст статьи
- **Целевая переменная:** log(1 + среднее число просмотров в день)

## Этапы

### 1. Парсинг
- Проверка robots.txt
- "Вежливые" запросы: случайная пауза 1-2 секунды, повтор при ответах 429/503
- Сбор ссылок, дат и просмотров со 100 страниц хаба (2000 статей)
- Скачивание полных текстов статей с сохранением прогресса

### 2. Подготовка данных
- Удаление коротких текстов (меньше 300 символов)
- Удаление статей моложе 3 дней
- Просмотры в день = просмотры / дни с момента публикации
- Логарифмирование целевой переменной из-за длинного правого хвоста
- Итог: 1952 статьи

### 3. Модель
- Разбиение train/test 80/20
- TF-IDF: униграммы и биграммы, стоп-слова (русские и английские), min_df=5, max_df=0.5, norm=None, sublinear_tf=True
- Ridge-регрессия, подбор alpha через GridSearchCV (5 фолдов)

## Результаты

- **Baseline** (предсказание среднего): R^2 = 0.000, RMSE = 0.954, MAE = 0.730
- **Ridge:** R^2 = 0.165, RMSE = 0.872, MAE = 0.658
- **Ridge без названий месяцев:** R^2 = 0.150, RMSE = 0.880, MAE = 0.664

Модель объясняет около 17% разброса популярности статей только по тексту и работает лучше baseline.

## Основные выводы

- **Больше просмотров:** статьи о свежих моделях и компаниях (strata, astra, anthropic, claude), практические материалы (код, промпт, гб), темы безопасности и прав.
- **Меньше просмотров:** короткие новости и анонсы продуктов (представлен, открытый проект, пояснили, сервис).
- **Найденное смещение:** названия месяцев попали в топ признаков. Модель через текст узнаёт возраст статьи, так как у старых статей ниже среднее число просмотров в день. Эксперимент с удалением месяцев показал, что они дают лишь небольшую часть качества (R^2 0.165 -> 0.150).
